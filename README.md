## // ==== Employee Management System (Java) ====  \\



A Java-based Employee Management System designed to demonstrate real-world object-oriented programming concepts through employee roles
, salary management, and bonus calculation.

 ## About the Project

This project models an employee management system where different types of employees share common properties and behaviors while
maintaining their own specialized functionality.

It uses Java's Object-Oriented Programming (OOP) principles to create a structured, reusable, and maintainable application.

## Key Features

- Employee management using an abstract parent class.
- Separate Developer and Manager employee roles.
- Encapsulation through private fields and public getters/setters.
- Inheritance for code reusability.
- Runtime polymorphism through method overriding.
- Abstraction using abstract classes and methods.
- Interface-based bonus eligibility.
- Role-specific bonus calculation.
- Employee salary and department information management.

## OOP Concepts Implemented

Concept| Implementation
Encapsulation| Private fields with getters and setters
Inheritance| Developer and Manager extend Employee
Polymorphism| Overridden bonus calculation methods
Abstraction| Abstract Employee class
Interface| BonusEligible interface

## How to Run

1. Make sure Java JDK is installed.

2. Clone the repository:

git clone YOUR_REPOSITORY_URL

3. Navigate to the project directory and compile:

javac *.java

4. Run the application:

java Main
